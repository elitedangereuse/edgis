# Exploration-ship benchmark library

SLEF/`Loadout`-shaped JSON for a spread of exploration ships, used to benchmark
the fuel-aware planner across ship profiles (jump range, tank capacity in
boosted jumps, reach growth, 4x vs 6x supercharge). The spread matters because
the planner behaves differently by profile: e.g. B2 range-growth helps
big-tank ships but can regress small-tank ones (see `run_ship_library_bench.py`
and the cobra mkV finding).

| file | tank (boosted jumps) | reach growth | supercharge |
|---|---|---|---|
| `diamondback_explorer.json` | 3 | 1.05 | 4x |
| `anaconda.json` | 3 | 1.03 | 4x |
| `asp_explorer.json` | 6 | 1.08 | 4x |
| `krait_phantom.json` | 6 | 1.08 | 4x |
| `mandalay.json` | 6 | 1.10 | 4x |
| `cobra_mkv.json` | 10 | 1.16 | 4x |
| `beluga.json` | 24 | 1.18 | 4x |
| `caspian.json` | 28 | n/a | 6x |

These are REPRESENTATIVE profiles, generated by `_build_library.py`: approximate
hull masses with the engineered FSD optimal-mass calibrated so the full-tank
range matches the community meta at siriuscorp.cc/guides/exploration.html and
pilotstradenetwork.com/ship-builds/exploration/. That makes the three
planner-relevant inputs correct (range, tank_jumps, reach-growth) without each
site's exact module list. `caspian.json` is a real game-sourced loadout.

**To add an exact build:** paste its EDSY URL into the plotter UI (From/To
panel, Ship section), which parses and can export the SLEF; save that JSON
here. Any file in this directory is picked up by `run_ship_library_bench.py`.

Regenerate the synthetic ones: `python3 _build_library.py`.

## PTN exact builds (`*_ptn.json`)

EXACT SLEF exports of the Pilots Trade Network exploration builds
(pilotstradenetwork.com/ship-builds/exploration/), added 2026-11-20. They
complement the synthetics with real module lists and extend the spread
downward: low-range hulls (Courier 48 ly, Cutter 54 ly, Type-10 53 ly,
Dolphin 59 ly) and thirsty 2-jump tanks the synthetic set lacked.
